Typical pipeline command:

  nextflow run genomic-medicine-sweden/tomte -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                             [string]  Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                            [string]  The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure. [default: results]  
  --email                             [string]  Email address for completion summary. 
  --multiqc_title                     [string]  MultiQC report title. Printed as page header, used for filename if not otherwise specified. 
  --save_mapped_as_cram               [boolean] Do you want to save bam as cram [default: true] 

Reference genome options
  --genome                            [string]  Name of genome reference, etiher hg19/GRCh37 or hg38/GRCh38, it is case sensitive.  (accepted: 
hg19, GRCh37, hg38, GRCh38) [default: GRCh38]  
  --fasta                             [string]  Path to FASTA genome file. 
  --gtf                               [string]  Path to GTF annotation file. 
  --gencode_annotation_version        [integer] Name of Genomes gencode reference version to download if fasta or gtf is not provided. [default: 
46]  
  --platform                          [string]  Specifies which platform was used for sequencing.  (accepted: illumina) [default: illumina] 
  --save_reference                    [boolean] If generated by the pipeline save the required indices/references in the results directory. 
[default: true]  
  --star_index                        [string]  Path to directory or tar.gz archive for pre-built STAR index. 
  --salmon_index                      [string]  Path to directory or tar.gz archive for pre-built Salmon index. 
  --transcript_fasta                  [string]  Path to transcript FASTA file. 
  --vep_cache                         [string]  Path to vep's cache directory. 
  --vep_cache_version                 [integer] Specifies version of vep cache to use.  (accepted: 107, 110, 112) [default: 112] 
  --vep_plugin_files                  [string]  Databases used by both named and custom plugins to annotate variants. 
  --skip_download_vep                 [boolean] Skip vep cache download. [default: true] 
  --skip_download_gnomad              [boolean] Skip gnomad reference download for vep. [default: true] 
  --skip_download_drop_mae_high_q_vcf [boolean] Skip download of reference VCF containing positions of SNPs that are usually called with high 
quality. Used in DROP MAE. [default: true]  
  --vep_refs_download                 [string]  Path to comma separated csv with paths to vep references to download, see example in 
test_data/vep_to_download.csv  
  --drop_mae_high_q_vcf               [string]  Path to vcf used by DROP MAE to make sure WGS vcf and bam file come from same individual 
  --drop_mae_high_q_vcf_tbi           [string]  Path to vcf tbi used by DROP MAE to make sure WGS vcf and bam file come from same individual 
 

Trimming options
  --min_trimmed_length                [integer] Discard trimmed reads shorter than this [default: 40] 

Alignment options
  --star_two_pass_mode                [string]  Set two pass mode for STAR  (accepted: Basic, None) [default: Basic] 
  --skip_subsample_region             [boolean] Turn off subsampling of the region. The region is defined by the subsample_bed parameter and the 
fraction is given by seed_frac. By default true if no subsample_bed is provided. [default: true] 
 
  --skip_downsample                   [boolean] Skip downsampling before expression/splicing analysis. The number of reads to be used is defined by 
num_reads. [default: false]  
  --subsample_bed                     [string]  Bed with regions to subsample 
  --seed_frac                         [number]  -s INT.FRAC is equivalent to --subsample-seed INT --subsample 0.FRAC in samtools view [default: 
0.001]  
  --num_reads                         [integer] Number of reads to downsample RNAseq sample to [default: 120000000] 

Variant calling
  --variant_caller                    [string]  Program to use for variant calling  (accepted: bcftools, gatk) [default: bcftools] 
  --bcftools_caller_mode              [string]  Run bcftools call in either consensus or multiallelic mode  (accepted: consensus, multiallelic) 
[default: multiallelic]  
  --skip_variant_calling              [boolean] Skip variant calling for all samples. [default: false] 
  --skip_build_tracks                 [boolean] Skip building splice junction tracks for IGV. [default: false] 
  --skip_stringtie                    [boolean] Skip analysis with StringTie [default: false] 
  --skip_vep                          [boolean] Skip Ensembl Variant Effect Predictor [default: false] 
  --skip_drop_ae                      [boolean] Skip DROP Aberrant Expression module  [default: false] 
  --skip_drop_as                      [boolean] Skip DROP Aberrant Splicing module [default: false] 
  --skip_export_counts_drop           [boolean] Skip export counts for DROP. It will export information from those modules run. Read usage for 
further information. [default: true]  
  --drop_group_samples_ae             [string]  DROP group to run when AE only one allowed. Make sure it matches your reference annotation file. 
[default: outrider]  
  --drop_group_samples_as             [string]  DROP group to run when AS only one allowed. Make sure it matches your reference annotation file. 
[default: fraser]  
  --drop_padjcutoff_ae                [number]  Adjusted p-value cut-off for DROP Aberrant Expression module [default: 0.05] 
  --drop_padjcutoff_as                [number]  Adjusted p-value cut-off for DROP Aberrant Splicing module [default: 0.1] 
  --drop_zscorecutoff                 [number]  Z-score cut-off for DROP Aberrant Expression module [default: 0] 
  --drop_add_af                       [boolean] Toggle whether DROP adds allele frequency annotations when running DROP MAE module. Requires 
internet access. [default: true]  
  --reference_drop_annot_file         [string]  Path to a tsv file containing sample annotation for DROP. Must be provided to run DROP. 
  --reference_drop_count_file         [string]  If you are running DROP Aberrant Expression, provide the path to a tsv or tsv.gz with counts from at 
least 50 samples to use as controls  
  --reference_drop_splice_folder      [string]  If you are running DROP Aberrant Splicing, provide the path to a folder with splice counts from at 
least 30 samples to use as controls, files inside folder must be tsv.gz  
  --gene_panel_clinical_filter        [string]  tsv file containing genes on which results from drop and vep will be filtered to avoid incidental 
findings, columns should be chromosome, gene_start, gene_stop, hgnc_id, hgnc_symbol  

QC options
  --skip_peddy                        [boolean] Do not calculate sex check using Peddy. [default: false] 
  --skip_calculate_hb_frac            [boolean] Do not calculate hemoglobin fraction among reads. [default: false] 
  --hb_genes                          [string]  Hemoglobin genes ensembl IDs 

Generic options
  --multiqc_methods_description       [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                              [boolean, string] Display the help message. 
  --help_full                         [boolean]         Display the full detailed help message. 
  --show_hidden                       [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
